# BADRO Data Cleaner

A Python desktop application for cleaning CSV files.

## Features
- Remove duplicate rows.
- Remove empty rows.
- Trim unnecessary spaces.
- Export cleaned CSV files.

## Technology
- Python
- Tkinter
- Pandas

## Installation
``bash
pip install -r requirements.txt
``

## Run
``bash
python badro_cleaner.py
``
