# BADRO Data Cleaner

A simple Python desktop application for cleaning CSV files.

## Features

- Remove duplicate rows.
- Remove completely empty rows.
- Trim unnecessary spaces from column names and cell values.
- Export cleaned data to a new CSV file.
- Simple desktop interface built with Tkinter.

## Technology

- Python
- Tkinter
- Pandas

## Installation

Install Python, then install Pandas:

```bash
pip install pandas
```

## Run

```bash
python badro_cleaner.py
```

## Project

BADRO Data Cleaner is a Python desktop utility designed to make CSV cleaning easier.
